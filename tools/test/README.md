# ชุดทดสอบระบบจอง

รัน worker.js ตัวจริงบน sqlite ในเครื่อง ไม่แตะฐานข้อมูลจริง ไม่ต้องต่อเน็ต

    node tools/test/scen.mjs     # เส้นทางลูกค้าปกติ + การกันจองซ้อน + การตรวจไฟล์
    node tools/test/scen2.mjs    # เคสหมดเวลา การกู้คืนห้อง การยืนยันสลิป การค้นหา

ต้องผ่านครบทุกข้อก่อน push ทุกครั้งที่แก้ worker.js

เคยจับบั๊กจริงมาแล้ว:
- CREATE INDEX อ้างคอลัมน์ที่ยังไม่ถูกเพิ่ม → ฐานข้อมูลใหม่ init ไม่ผ่าน
- โค้ดกู้คืนห้องใน uploadSlip ไม่เคยทำงาน เพราะมี early return คั่นอยู่ข้างบน
