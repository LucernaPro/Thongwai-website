## บั๊กจริงที่ชุดนี้เคยจับได้

- CREATE INDEX อ้างคอลัมน์ที่ยังไม่ถูกเพิ่ม → ฐานข้อมูลใหม่ init ไม่ผ่านทั้งระบบ
- โค้ดกู้คืนห้องใน uploadSlip ไม่เคยทำงาน เพราะมี early return คั่นอยู่ข้างบน
- บล็อกตั้งราคาสองแบบรันก่อน seed ห้อง → ห้องที่สร้างใหม่ไม่มีราคารวมอาหารเช้า
- cancel ไม่เช็คสถานะเดิม → กดซ้ำรายงานว่าสำเร็จและเขียน audit เพิ่มทุกครั้ง
- พนักงานตั้งใจยกเลิกรายการที่จ่ายแล้ว → หน้าตรวจขึ้นแดงค้างตลอดไปทั้งที่จัดการแล้ว
- ไฟล์สำรอง CSV ไม่มีคอลัมน์ยอดเงิน/สถานะการจ่าย → กู้ระบบแล้วไม่รู้ว่าใครจ่ายเท่าไหร่

ทั้งสามตัวเป็นชนิดเดียวกัน: โค้ดถูกทุกบรรทัด แต่ลำดับการทำงานผิด — อ่านโค้ดอย่างเดียวมองไม่เห็น
