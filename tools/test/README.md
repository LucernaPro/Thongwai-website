# ชุดทดสอบระบบจอง

รัน worker.js ตัวจริงบน sqlite ในเครื่อง ไม่แตะฐานข้อมูลจริง ไม่ต้องต่อเน็ต

    sh tools/test/run-all.sh

ต้องผ่านครบทุกเคสก่อน push ทุกครั้งที่แก้ worker.js

| ไฟล์ | ครอบคลุม |
|---|---|
| scen.mjs  | เส้นทางลูกค้าปกติ · กันจองซ้อน · ตรวจไฟล์สลิป |
| scen2.mjs | หมดเวลาระหว่างไปโอน · กู้คืนห้อง · ยืนยันสลิป · ค้นหาการจอง |
| scen3.mjs | วันที่มั่ว · ราคาข้ามเทศกาล · เดากุญแจ · เรียก API โดยไม่ล็อกอิน · ข้อมูลแปลกปลอม |
| scen4.mjs | ฐานข้อมูลใหม่เอี่ยม · งานพนักงาน · จองพร้อมกัน · หน้าตรวจระบบจับของจริง |
| scen5.mjs | ความถูกต้องของเงิน — ทุกวันในสัปดาห์ ทุกเทศกาล เตียงเสริม ยอดที่ล็อกไว้ |

## บั๊กจริงที่ชุดนี้เคยจับได้

- CREATE INDEX อ้างคอลัมน์ที่ยังไม่ถูกเพิ่ม → ฐานข้อมูลใหม่ init ไม่ผ่านทั้งระบบ
- โค้ดกู้คืนห้องใน uploadSlip ไม่เคยทำงาน เพราะมี early return คั่นอยู่ข้างบน
- บล็อกตั้งราคาสองแบบรันก่อน seed ห้อง → ห้องที่สร้างใหม่ไม่มีราคารวมอาหารเช้า

ทั้งสามตัวเป็นชนิดเดียวกัน: โค้ดถูกทุกบรรทัด แต่ลำดับการทำงานผิด — อ่านโค้ดอย่างเดียวมองไม่เห็น
